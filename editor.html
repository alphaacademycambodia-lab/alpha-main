Edit any page on the site visually

Open a page's HTML file (from this same folder) to start — index.html for Home, services.html, about.html, or any other page. Everything runs locally in your browser — no changes are ever posted to the website.

  • Click any photo or illustration to replace it with your own image.
  • Click into any text on the page and type to edit it directly.
  • Use Insert to add a new section, text, photo, YouTube video or button anywhere on the page.
  • Click a block once to select it, then use Duplicate, Move Up / Move Down, or Delete Block.
  • Click any link to enable Edit Link and change where it points.
  • Your work autosaves in this browser as you go, so an accidental tab close isn't fatal — reopen the same file to be offered your draft back.
  • When you're happy, click Export page to download the finished file — under its original name, ready to upload to your website.
Tip: keep this editor file in the same folder as your site's pages and the assets/ folder.
