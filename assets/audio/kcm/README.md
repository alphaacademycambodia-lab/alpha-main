# Khmer Conversational Mastery — recorded audio

Put one MP3 per Khmer line here. The lesson page plays these first and falls
back to the device's Khmer voice for any line that has no file yet.

File names: `NNN-dLL.mp3` = situation NNN, dialogue line LL;
`NNN-pLL.mp3` = situation NNN, phrase LL (both counted from 1, zero-padded).
Example: `001-d03.mp3`, `012-p05.mp3`.

The full list of file names with the Khmer text to read is in the
KCM recording script spreadsheet. Record at normal speed; the page's
"Slow" button plays the file at 75%.
