រូបមន្តគីមីសំខាន់ៗ Key Chemical Formulas Formules chimiques clés

ម៉ូល និងមាឌMoles and volumeMoles et volume

  • n = m / M
  • n = V / VM
  • n = N / NA  (NA = 6.02 × 1023)
  • STP (0 °C, 1 atm): VM = 22.4 L/mol
  • RTP (25 °C, 1 atm): VM = 24 L/mol
  • PV = nRT  (R = 8.314 J·mol−1·K−1)

កំហាប់សូលុយស្យុងConcentrationConcentration

  • Cm = m / Vs
  • C = n / Vs  |  C = Cm / M
  • C1V1 = C2V2
  • C% = (m / ms) × 100%
  • pH = −log[H+]
